About these maps

Each map is a single page built from the festival's own published schedule. It works on phones, and the full schedule is also a plain list, so you can use it with a keyboard or screen reader.

Times can change on the day, so check each festival's official site for rain plans and updates. Spotted a mistake or want your town added? Open an issue on GitHub.

Made by volunteers at Boston Open Dev, a casual open source meetup. Source on GitHub.
